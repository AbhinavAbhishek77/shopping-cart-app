# 🛒 Shopping Cart App

A simple and fast shopping cart web app built with React, Redux Toolkit, and Tailwind CSS. Users can browse products, add items to the cart, and see totals update instantly. The layout is clean, responsive, and easy to navigate.

---

### 👉 Live Demo  
**https://shopping-cart-app10.vercel.app/**

---

## 🚀 Features

- Product listing  
- Add to cart  
- Remove from cart  
- Real time cart updates  
- Global state handling with Redux Toolkit  
- Responsive UI built with Tailwind CSS  

---

## 🛠️ Tech Stack

- **React** 
- **Redux Toolkit**  
- **Tailwind CSS**  

---

- Building reusable React components
